 │  錄音 (MediaRecorder) / 文字輸入       │
 └───────┬──────────────────────────────┘
         │ REST /api/*
 ┌───────▼──────────── 後端 Flask ───────────────────────────────┐
 │                                                               │
 │  語音 ──► AWS Transcribe (zh-TW) ──► 詞彙校正 (agri_terms)     │
 │                                         │                     │
 │                                         ▼                     │
 │                          日誌解析 (OpenAI JSON / 規則式)        │
 │                                         │                     │
 │                                         ▼                     │
 │                         儲存 (Firestore / 本機 JSON)           │
 │                           │                     │             │
 │                           ▼                     ▼             │
 │                 產銷履歷草稿 (欄位對應)   行銷文案 (4P prompt)   │
 │                                                               │
 │  問答 ──► 風險分級 ──► 本地向量檢索 ──► 官方網站 search agent    │
 │                              └──────┬──────┘                  │
 │                         有來源 → OpenAI 依來源作答 + 引用        │

## 設計原則

- **每個外部服務都有備援**：`LLMClient.available`、`SpeechService.transcribe_available` 等屬性讓呼叫端在金鑰缺少或服務失敗時退回離線流程，系統不會因單一服務故障而無法使用。
- **只根據來源回答**：問答的 system prompt 限制模型只能使用檢索到的資料，且來源不足時直接回覆資料不足。
- **高風險問題一律警示**：`safety.assess_risk` 以關鍵詞判斷是否涉及用藥劑量、混藥、人體健康、禁用藥劑、安全採收期，命中時無論是否有答案都會附加警示。
- **文案不捏造事實**：行銷文案只使用農事紀錄與使用者填寫的產品資訊，prompt 明確禁止誇大療效或虛構認證。
